Flexbox

Até 2008 o mecanismo de posicionamento exitente no CSS eram: fluxo do html, float e positions, mas em 2007 se popularizou dispositivos moveis. Para possibilitar uma maior responsividade o CSS 3 trouxe alguns recursos como screen media, que permite definir conjuntos de regras diferentes para com base no tamanho da tela do usuario e também a propriedade display:flex, que especifica o mecanismo FlexBox de posicionamento dos elementos HTML

Para definir um componente como um container flex basta definir o display:flex

        <style>
            .container{display: flex}
        </style>

        <div class=".container">
            ...
        <div>
