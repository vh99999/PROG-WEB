O que é JavaScript?

É uma linguagem de programação, interpretada, para desenvolvimento web que é executada sobre o navegador do cliente em um sandbox, que limita o acesso aos recursos do sistema operacional, fornecendo interfaces pre-definidas, a forma de acesso a recursos do sistema se faz por meio de objetos globais disponibilizados ao navegador, como: document, history, local storage e console. Ela foi criada para adicionar dinamismo e interatividade nas paginas. A tipagem é dinamica forte, permitindo que variaveis possam ser atribuidas e reatribuidas a qualquer momento, sem a nessesidade de declarar seu tipo previamente. Os tipos de dados nativos da linguagem são: Number, String, Boolean, Object, Array e Function
